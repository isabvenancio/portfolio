## ▶️ Executando localmente

Clone o projeto:

```bash
git clone https://github.com/isabvenancio/portfolio.git
```

Entre na pasta:

```bash
cd portfolio
```

Instale as dependências:

```bash
npm install
```

Execute:

```bash
npm run dev
```

## 📦 Build

Para gerar uma versão de produção:

```bash
npm run build
```
